# MySteamlikeAssistant（鼠标视角助手）

魔兽世界 **3.3.5a（WLK）** 插件。把由手柄映射软件 / 安卓模拟器注入的两个特殊按键 **F11 / F12**
转换为「鼠标视角」操作，效果**等同于按住鼠标右键拖动视角**；
并在使用 W/A/S/D 方向键移动时可选地自动锁定鼠标视角（默认关闭）。

> ⚠️ F11 / F12 的映射由「**按键映射**」开关控制，**默认关闭**（插件不占用这两个键）。
> 首次使用请在 `Esc → 界面 → MySteamlikeAssistant` 中勾选，或输入 `/msa bind` 开启。

- **按 F11**：若当前不在鼠标视角，则**开启**鼠标视角（`MouselookStart`）
- **按 F12**：**关闭**鼠标视角（`MouselookStop`）
- **按 W/A/S/D 移动**：若当前不在鼠标视角，则**自动开启**（可用开关控制，见下）
- **标记骷髅**：按一下把当前目标标记为团队标记；**编号（1–8）与按键都可在设置面板里改**，默认 8 号骷髅、按键 `\`（默认关闭）

典型用途：安卓手柄 → 模拟器（如 Winlator）/ 键盘映射软件 → 注入 `F11` / `F12` → 本插件接收 → 控制游戏视角。

---

## 一、功能特性

| 功能 | 说明 |
| --- | --- |
| 按键映射开关 | F11 / F12 是否映射为鼠标视角，可在设置面板勾选或 `/msa bind` 切换；**默认关闭**，关闭时不占用这两个键 |
| 标记骷髅 | 把当前目标标记为团队标记，**编号可在 1–8 中选择**（默认 8 号骷髅），带独立开关（**默认关闭**），默认按键 `\` |
| F11 开启视角 | 内部先用 `IsMouselooking()` 判断，已在视角中则不会重复开启 |
| F12 关闭视角 | 直接调用 `MouselookStop()` |
| 移动自动锁视角 | 用 W/A/S/D 方向键开始移动时，若不在视角中则自动开启；带独立开关（**默认关闭**） |
| 锁定状态自愈 | 锁定期间每 0.5 秒兜底检查一次视角状态，客户端若从非右键途径退出视角会自动重置标记，下次移动可重新锁定 |
| 登录自动挂钩 | 在 `PLAYER_LOGIN` 时按当前开关状态自动绑定（或解绑）并持久化，重载 / 重登后依然有效 |
| 状态自检 | 命令 `/msa` 可查看按键绑定是否生效、当前视角状态、各开关状态 |
| 不污染按键面板 | 采用「隐藏按钮 + `SetBindingClick`」，不会出现在游戏「按键设置」界面中 |

## 三、安装

1. 把整个 `MySteamlikeAssistant` 文件夹放到：
   `...\World of Warcraft\Interface\AddOns\MySteamlikeAssistant\`
2. **完全退出客户端后重新启动**。
   - ⚠️ 重要：客户端**只在启动时扫描** `Interface\AddOns` 目录。
     如果你是在客户端运行期间才创建/添加的插件文件夹，`/reload` 或退回角色选择界面**都不会**让它出现，必须彻底关闭进程再重开。
3. 在**角色选择界面**点击「插件 / AddOns」按钮，确认 **MySteamlikeAssistant** 在列表中且已勾选启用。
   - 若显示为「不兼容 / 过期」，勾选右上角「加载过期插件」。
4. 进入游戏，输入 `/msa`。若能看到 `[MSA] 按键映射: ...` 即安装成功。
   - 此时 `F11 绑定` 显示 `未生效` 属于正常现象：按键映射**默认关闭**，需按上一节开启。

## 四、使用方法

首次使用需要先开启「按键映射」：进入 `Esc → 界面 → MySteamlikeAssistant` 勾选
**按键映射（F11 开 / F12 关）**，或直接输入 `/msa bind`。开启后正常游玩无需任何操作，
直接使用手柄映射出来的按键即可：

| 操作 | 行为 |
| --- | --- |
| 按 `F11` | 开启鼠标视角（移动鼠标转动视角）（前提：「按键映射」为开启） |
| 按 `F12` | 关闭鼠标视角（前提：「按键映射」为开启） |
| 按 `W/A/S/D` 移动 | 自动开启鼠标视角（前提：该功能开关为「开启」） |

「按键映射」关闭时插件**不会占用** F11 / F12（若之前开启过会自动解绑），
`/msa start`、`/msa stop` 命令仍然可用。

### 标记骷髅（默认关闭）

用于把手柄上的某个按键映射成“标记当前目标”，方便拉怪 / 集火。

1. `Esc → 界面 → MySteamlikeAssistant`，勾选 **标记骷髅**。
2. 按键默认是 **`\`**（回车键上面那个）。如需更换，点击 **设置按键：\** 按钮，
   然后按下你要用的那个键（`Esc` 或再点一次按钮取消）。
   按键可以是单个键，也可以带 `Shift` / `Ctrl` / `Alt` 组合，例如 `SHIFT-F10`。
3. 在 **标记编号** 下拉框里选择要用的编号（默认 8 号骷髅），每项都带形状说明：

   | 编号 | 标记 | 编号 | 标记 |
   | --- | --- | --- | --- |
   | 1 | 星形（黄色五角星） | 5 | 月亮（银白弯月） |
   | 2 | 圆形（橙色圆环） | 6 | 方块（蓝色方块） |
   | 3 | 菱形（紫色菱形） | 7 | 十字（红色叉形） |
   | 4 | 三角（绿色三角） | 8 | 骷髅（白色骷髅头） |

4. 进游戏选中目标，按该键即可给目标打上所选标记。

- 开关默认**关闭**；按键默认 `\`、编号默认 `8`。开启开关后按键立即生效（绑定会写入磁盘）。
- 关闭开关时会自动解绑，不占用玩家的按键。
- 团队标记只能在**小队 / 团队**中生效；没有目标或单人时插件会在聊天框提示。
- 若录制的按键是 `F11` / `F12`，插件会拒绝并提示，避免覆盖鼠标视角绑定。
- 若某客户端不识别 `\`（绑定静默失败），插件会提示“未能生效”，此时请在面板里换一个键。

建议把「按下视角键 → 发送 `F11`」「松开视角键 → 发送 `F12`」映射到同一个手柄按键上，
即可获得「按住看视角、松开停止」的手感。

「移动自动锁视角」用于让相机在移动时自动跟随（**默认关闭**，需 `/msa wasd` 开启）。
它**只负责开、不负责关**：移动开始时会自动进入鼠标视角，需要退出时按 `F12`（或用手柄映射停止键）。

## 五、斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/msa` | 查看状态：按键映射开关 + 两个按键的绑定情况 + 当前是否处于鼠标视角 + 各开关状态 |
| `/msa start` | 手动开启鼠标视角（用于验证 API 是否可用） |
| `/msa stop` | 手动关闭鼠标视角 |
| `/msa bind` | 开 / 关「按键映射」（F11 / F12 是否绑定到鼠标视角，默认**关闭**） |
| `/msa rebind` | 重新挂载绑定并持久化（绑定被重置后可用它恢复；会同时开启按键映射） |
| `/msa skull` | 开 / 关「标记骷髅」（默认**关闭**；按键需在设置面板里录制） |
| `/msa wasd` | 开 / 关「移动自动锁视角」（默认**关闭**） |
| `/msa help` | 显示全部可用命令（帮助） |
| `/msa debug` | 开 / 关调试日志：打开后每次收到 F11/F12 或触发自动锁视角都会在聊天框打印一行 |
| `/msa diag` | **临时诊断**：开 / 关后每秒打印一行客户端内部的鼠标状态（视角是否开启、客户端收到的光标坐标、鼠标在哪个框体、左右键状态），排查输入层问题用，定位后即移除 |
| `/bridge` | 与 `/msa` 完全等价的别名 |

`/msa` 的典型输出：

```
[MSA] 按键映射: 开启
[MSA] F11 绑定: CLICK MSA_Btn_F20:LeftButton
[MSA] F12 绑定: CLICK MSA_Btn_F21:LeftButton
[MSA] 当前鼠标视角: 关闭
[MSA] 移动自动锁视角: 关闭
[MSA] 标记骷髅: 关闭（按键: \，编号: 8 - 骷髅（白色骷髅头））
[MSA] 调试日志: 关闭
[MSA] 输入 /msa help 查看全部命令
```

- 出现 `CLICK MSA_Btn_F20:LeftButton` 表示**绑定已生效**（客户端认识 F11）。
  `MSA_Btn_F20` 只是内部按钮名，与具体按键无关。
- 出现 `未生效` 表示该按键当前没有绑定。若「按键映射」显示为 `关闭`，这是预期状态；
  开启映射后仍显示 `未生效`，说明该按键未被客户端接受，需要换键（见「七、自定义」）。

### 查看日志

按键本身不会常驻打印日志（否则正常游玩会刷屏）。需要排查时：

1. 输入 `/msa debug` 打开调试日志。
2. 按下 F11 / F12（或按 W/A/S/D 移动），聊天框会各打印一行，例如：

   ```
   [MSA] 收到按键 F11（鼠标视角: 开启）
   [MSA] 收到按键 F12（鼠标视角: 关闭）
   [MSA] 方向键移动触发自动锁视角（MoveForwardStart）
   ```

3. 排查完再输入一次 `/msa debug` 关闭。

日志输出去向：**游戏聊天框**（默认在「综合」标签页，可用鼠标滚轮上翻查看）。
若按了键却没有任何输出，说明按键没有送达客户端（问题在手柄 / 模拟器映射一侧）。

## 六、工作原理

### 1. F11 / F12 的控制链路

1. **键位从哪来**：手柄软件 / 模拟器把某个手柄按键「翻译」成键盘上的 `F11`、`F12`，
   再由 Windows 送到游戏客户端。
2. **插件如何接到按键**：WoW 里能可靠接收“任意按键”的机制是**按键绑定**。
   插件用 `SetBindingClick("F11", "MSA_Btn_F20")` 把 F11 绑定为「点击名为 `MSA_Btn_F20` 的按钮」。
   这一步受「按键映射」开关控制：开关关闭时插件不绑定（并解绑自己之前占用的键），
   所以首次使用需要先开启。解绑同样会 `SaveBindings` 落盘，避免残留。
3. **按键触发流程**：
   ```
   按下 F11  →  客户端执行“点击 MSA_Btn_F20”  →  触发按钮 OnClick
             →  StartMouselook()  →  if not IsMouselooking() then MouselookStart() end
   ```
   F12 同理，`OnClick` 里直接调用 `MouselookStop()`。
4. **为什么用隐藏按钮**：`SetBindingClick` 走的是“点击按钮”这条路径，不需要 `Bindings.xml`，
   也不会在「按键设置」界面里留下条目，干净且不冲突。
5. **为什么要在 `PLAYER_LOGIN` 挂钩**：此时按键表已加载完成，`SetBindingClick` + `SaveBindings`
   才能正确落盘，保证下次登录依然有效。登录时按存档里的开关状态决定“绑定”还是“解绑”。

### 2. 「移动自动锁视角」的实现

参考 ConsolePort 的做法：**不重绑 W/A/S/D**（那会破坏移动功能），
而是用 `hooksecurefunc` 给游戏的“开始移动”函数挂一个**后置钩子**。
玩家按方向键时，客户端会调用这些函数，钩子在原函数执行完之后再触发，
于是我们能在**不改变移动行为**的前提下顺带打开鼠标视角：

| 被挂钩的函数 | 对应按键（WoW 默认键位） |
| --- | --- |
| `MoveForwardStart` | W（前进） |
| `MoveBackwardStart` | S（后退） |
| `TurnLeftStart` | A（左转） |
| `TurnRightStart` | D（右转） |
| `StrafeLeftStart` | Q（左平移） |
| `StrafeRightStart` | E（右平移） |

> 注意：WoW 默认键位里 **A/D 是“转向”（Turn），Q/E 才是“平移”（Strafe）**。
> 因此 A/D 对应的是 `TurnLeftStart` / `TurnRightStart`，必须一并挂钩，否则按 A/D 不会触发。
> 若你把 A/D 改绑成了平移，对应的仍是 Strafe 系列，所以这里两组都挂钩，做到全覆盖。

钩子内部逻辑：若 `wasdAutoLock` 开启且本次尚未自动锁定过，则调用 `MouselookStart()`
并记下「已锁定」标记；之后继续按方向键会直接短路，不再重复判断视角状态。

> `hooksecurefunc` 保证钩子一定在原函数**之后**执行，且**不覆盖**原函数，
> 所以对移动本身没有任何副作用。

**「已锁定」标记的重置（决定什么时候会再次自动锁定）**

| 触发方式 | 说明 |
| --- | --- |
| 按 F12 / `/msa stop` | 主动停止视角 |
| 按下或松开鼠标右键 | 手动转向 / 看视角 |
| 兜底检测 | 锁定期间每 0.5 秒检查一次 `IsMouselooking()`，发现视角已被客户端自行关闭就重置标记 |

最后一条是「自愈」用的。如果没有它，客户端一旦从**非右键途径**退出鼠标视角
（打开会捕获鼠标的界面、切出游戏窗口、点到 UI 元素等），插件会一直以为还在锁定，
之后按 W/A/S/D 全部被短路，视角就再也锁不回来 —— 外部表现就是
**相机不转，但光标可见、划过界面还会弹提示框**，只能重载界面才能恢复。

### 3. 「标记骷髅」的按键与录制

- **为什么按键要自己录**：3.3.5a 没有“运行时往游戏的按键设置里加条目”的接口（那需要 `Bindings.xml`），
  所以插件在设置面板里自己录：点击按钮后用 `EnableKeyboard(true)` 临时接管键盘，
  `OnKeyDown` 收到第一个非修饰键即算完成，再用 `SetBindingClick` 把它绑到隐藏按钮 `MSA_Btn_Skull`。
- **触发流程**：
  ```
  按下你录制的键  →  客户端执行“点击 MSA_Btn_Skull”  →  按钮 OnClick
                  →  MarkTargetSkull()  →  SetRaidTarget("target", 所选编号)
  ```
- **编号含义**：`SetRaidTarget` 的编号 1–8 依次是星形、圆形、菱形、三角、月亮、方块、十字、骷髅；
  面板里的下拉框就是按这个顺序列出，并附带形状说明，默认 8 号（骷髅）。
- **为什么要判断小队/团队**：团队标记图标只有在小队 / 团队中才会显示，单人时先提示一下，
  避免玩家以为“按了没反应”。

### 用到的游戏 API

| API | 说明 |
| --- | --- |
| `IsMouselooking()` | 返回当前是否处于鼠标视角 |
| `MouselookStart()` | 开启鼠标视角 |
| `MouselookStop()` | 关闭鼠标视角 |
| `SetBindingClick(key, buttonName)` | 把某个键绑定为“点击某个按钮” |
| `GetBindingAction(key)` | 查询某个键当前绑定的动作 |
| `SaveBindings(set)` | 把按键绑定写入磁盘持久化 |
| `GetCurrentBindingSet()` | 返回当前生效的按键方案编号 |
| `SetRaidTarget(unit, index)` | 给单位打团队标记（1–8 依次为星形、圆形、菱形、三角、月亮、方块、十字、骷髅） |
| `EnableKeyboard(enable)` / `OnKeyDown` | 临时接管键盘，用于在面板里录制按键 |
| `hooksecurefunc(name, fn)` | 给全局函数挂后置钩子（不覆盖原函数） |

## 七、自定义

### 更换接收的按键

编辑 `MySteamlikeAssistant.lua` 顶部两行即可：

```lua
local START_KEY = "F11"   -- 改成你需要的键
local STOP_KEY  = "F12"   -- 改成你需要的键
```

改完后 `/reload` 或重新登录生效。可用 `/msa` 确认是否变为 `CLICK ...`。

> 注意：绑定会持久化写盘，**改常量不会自动解绑旧键**。
> 若旧键（如 F20/F21）仍会触发，可在游戏「按键设置」里手动清除，或忽略它。

### 按键映射（F11 / F12）

- 默认**关闭**：插件不绑定、也不占用 F11 / F12。
- 开启方式：设置面板勾选「按键映射（F11 开 / F12 关）」，或输入 `/msa bind`。
- 开关状态会写入存档，重载 / 重登后保持。关闭时会自动解绑本插件之前占用的按键。

### 移动自动锁视角

- 默认**关闭**，用 `/msa wasd` 切换。
- 该开关会写入存档，`/reload` 后保持上次的状态。
- 若想改首次安装时的默认值，编辑 `MySteamlikeAssistant.lua` 中的 `local wasdAutoLock = false`（改成 `true` 即默认开启）。

### 其它说明

- 绑定名称（`MSA_Btn_F20` / `MSA_Btn_F21`）是全局唯一的按钮名，一般无需改动。
- 若某次在游戏的「按键设置」里点了「恢复默认」，本插件的绑定会被清除；
  重新登录或执行 `/msa rebind` 即可恢复。

## 八、常见问题（FAQ）

**Q1：游戏里输入 `/msa` 没反应，提示没有该命令？**
说明插件根本没被加载。依次检查：
1. 是否在**客户端运行期间**才放入插件文件夹 —— 必须**完全重启客户端**（`/reload` 无效）。
2. 角色选择界面的「插件」列表中是否勾选了 MySteamlikeAssistant。
3. 文件夹名与 `.toc` 文件名是否完全一致（都必须是 `MySteamlikeAssistant`）。

**Q2：`/msa` 里 `F11 绑定:` 显示 `未生效`？**
先看 `按键映射:` 这一行——若显示 `关闭`，属正常（默认不映射），用 `/msa bind` 或设置面板开启。
若映射已开启仍显示 `未生效`，说明该客户端不识别 F11 这个键，按「七、自定义」换成客户端支持的键。

**Q3：`/msa start` / `/msa stop` 有效，但按 F11 / F12 没反应？**
先确认「按键映射」已开启（`/msa` 第一行显示 `开启`）。
若已开启仍无反应，说明按键没有送达客户端，问题在**手柄映射 / 模拟器一侧**，不是插件。
可用普通键先验证映射链路是否正常。

**Q4：视角能开但不能关？**
确认松开手柄按键时确实发送的是 `F12`；必要时用 `/msa` 观察状态是否在两次按键间切换。

**Q5：重载界面后绑定失效了？**
插件在 `PLAYER_LOGIN` 会按存档中的开关状态自动重挂，正常情况下不会失效。若被「恢复默认」清掉，执行 `/msa rebind`。

**Q6：想让移动时自动锁视角？**
默认是**关闭**的，输入 `/msa wasd` 开启。开关会写入存档，之后重载 / 重登会保持开启状态。

**Q7：怕「移动自动锁视角」破坏移动？**
不会。它只是给移动函数挂了后置钩子，**不改动** W/A/S/D 的移动绑定与行为。

**Q8：偶尔视角突然锁不住（相机不转），但鼠标能动、划过界面还会弹提示框？**
原因是客户端从**非右键途径**退出了鼠标视角（打开会捕获鼠标的界面、切出游戏窗口、
点到 UI 元素等），而插件当时仍以为「已锁定」，于是把后续 W/A/S/D 全短路了。
现版本已内置兜底检测（每 0.5 秒一次），正常情况下会自动重置标记：
**松开再按一次 W/A/S/D** 即可重新锁定。
若仍然卡住，按住视角键（F11）或输入 `/msa start` 可以直接把视角抢回来，
无需重载界面。排查时可先 `/msa debug` 打开日志，日志会打印
「视角已被客户端关闭（非右键途径），自动锁定标记已重置」。

## 九、验证结论

- **界面版本**：`## Interface: 30300`（对应 3.3.5a）。
- **F11 / F12 可绑定**：目标 3.3.5a 客户端**支持**扩展功能键，`/msa` 实测返回
  `CLICK MSA_Btn_F20:LeftButton` / `CLICK MSA_Btn_F21:LeftButton`。

- **移动钩子可用**：`MoveForwardStart` 等函数可被 `hooksecurefunc` 挂钩（ConsolePort 亦采用同一做法）。
